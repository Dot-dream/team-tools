# CLAUDE.md 章节要点

> 供 P3 手写 CLAUDE.md 时的结构参考（用 `/init` 时也按此核对是否覆盖完整）。

## 必备章节

### 1. Project Overview
- 项目定位一句话 + 技术栈（MCU/语言/框架）
- 关键架构事实：如"APP/BOOT 共享源码靠宏切换"这类跨多文件才能看出的信息

### 2. Build System
- 构建工具/IDE 与工程文件位置（.ewp/.eww/Makefile/CMakeLists）
- 多工程/多配置表（工程 / 路径 / 用途 / 关键差异）
- 产物合并/打包命令（来自真实脚本，如 .bat/Makefile，**不要编造**）
- 烧录/部署方式

### 3. Key Compile Macros（有宏/条件编译时必备）
| 宏 | 定义位置 | 作用 |
- 特别标注"当前状态"（如某宏被 `#if 0` 禁用，实际生效分支是什么）

### 4. Architecture (big picture)
- 分层结构（文字图或代码块）
- 源码布局（每个顶层目录一句职责）
- 模块调用关系（谁调谁、数据流路径）
- 分区/变体（如 Bootloader 与 App 的跳转机制）

### 5. Development Notes & Gotchas
- 已知坑、`#if 0` 死代码、未接线逻辑、遗留缺失函数
- 代码复用方式（共享源码、独立子仓库）
- 需要两侧保持一致的文件（如共享头文件）

### 6. Code Intelligence（若配了工具）
- codegraph 索引位置与常用命令
- 知识库位置与入口

## 禁忌
- 不写"提供错误提示""写单元测试"这类通用废话
- 不列出可通过目录树轻易发现的完整文件清单
- 不编造"常见开发任务/技巧"（除非 README/文档里有）
