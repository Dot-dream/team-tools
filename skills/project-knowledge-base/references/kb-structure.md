## 笔记规范

### frontmatter（每条笔记必带）
```yaml
---
title: 笔记名
tags: [项目名, 模块, ...]
created: YYYY-MM-DD
---
```

### wikilink 规则
- 用 `[[笔记名]]` 关联相关笔记（首页导航的链接必须能解析到真实文件）
- 笔记结尾必须有「相关笔记」小节，链接 2~4 条关联笔记
- 行内代码示例中的 `[[...]]` 要放在反引号内，避免被识别为链接

### 内容要求
- 引用代码用 `文件路径:行号` 格式
- 流程/状态/时序**优先用 Mermaid 图表**，不用大段 ASCII 或纯文字
- 模块笔记结构遵循 `templates/module-note.md`

### 图表约定（首页需附说明）
| 图类型 | 用途 |
|---|---|
| `mindmap` | 导航/概览（树状） |
| `flowchart` | 分层/流程/数据流 |
| `stateDiagram-v2` | 状态机 |
| `sequenceDiagram` | 时序/调用顺序 |

## 首页 MOC 必备内容
1. 项目定位一句话
2. Mermaid mindmap 导航（见 `templates/home-moc.md`）
3. 知识地图（按模块分组的 wikilink 列表）
4. 关键构建宏/开关表
5. 图表约定说明
6. 关联外部项目/依赖仓库
